# Sir Shakes: Till The Last Drop
3D survival RPG s černým humorem ve středověkém prostředí (Unity, C#).

## Mechaniky
- alkoholový systém (3 úrovně), hlad, spánek
- reputace a charisma, krádeže a stráž
- questy a dialogy z JSON, společník Tonda
