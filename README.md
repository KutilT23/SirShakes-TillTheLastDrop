# Sir Shakes: Till The Last Drop

3D survival RPG s černým humorem ve středověkém prostředí.
Autor: Tomáš Kutil • Unity, C# • stav: alpha (hratelná verze)

Hráč je vyhnaný rytíř, který se probudí v zapadlé vesnici s obřím dluhem
v hospodě. Musí přežít, hlídat si alkohol, hlad, spánek a životy,
plnit questy a splatit dluh.

## Hlavní mechaniky
- alkoholový systém (3 úrovně) ovlivňující sílu, rychlost a dialogy
- hlad, spánek, životy, charisma a reputace u NPC
- krádeže, nahlášení stráži a konfrontace se strážným
- questy navázané na sebe, dialogy načítané z JSON
- obchodování s NPC: nákup a prodej itemů za groše, examine před koupí
- společník Tonda, který radí s questy a ovládáním
- inventář s popisem předmětů, truhly, den a noc
